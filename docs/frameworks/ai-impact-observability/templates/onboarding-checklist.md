## Propósito

Este checklist trackea el progreso de onboarding de nuevos developers Flutter y mide el tiempo hasta productividad plena (70-80% del nivel de un senior).

**Milestone de Productividad**: Cuando el developer completa Fase 3 sin ayuda significativa.

---

## Fase 1: Setup y Primer PR (Semana 1)

**Meta**: Entorno funcional y primer contribución trivial

- [ ] **Día 1**:  Setup de laptop (Flutter SDK, IDE, Git)
- [ ] **Día 1**: Acceso a repos (GitHub/GitLab), Firebase, CI/CD
- [ ] **Día 1-2**: Clonar proyecto, ejecutar app locally (iOS + Android)
- [ ] **Día 2-3**: Completar onboarding docs del equipo
- [ ] **Día 3-5**: Primer PR trivial merged (typo fix, comentarios, README)

## Fase 2: Primera Feature Pequeña (Semanas 2-3)

**Meta**: Contribución independiente a feature simple

- [ ] **Semana 2**: Asignado a primera feature pequeña (< 3 story points)
- [ ] **Semana 2**: Code review de código existente con mentor (2-3 archivos)
- [ ] **Semana 2-3**: Implementar feature (con ayuda de mentor)
- [ ] **Semana 3**: Tests unitarios/widget tests escritos
- [ ] **Semana 3**: PR creado y code review completado
- [ ] **Semana 3**: Feature merged y deployed a staging

## Fase 3: Contribución Mediana Independiente (Semanas 4-6)

**Meta**: Trabajar con mínima supervisión en feature de complejidad moderada

- [ ] **Semana 4**: Asignado a feature mediana (3-5 story points)
- [ ] **Semana 4**: Diseño técnico revisado con mentor (solo validación, no step-by-step)
- [ ] **Semana 4-5**: Implementación independiente (mentor disponible para preguntas)
- [ ] **Semana 5**: Testing comprehensivo (unit + widget + integration)
- [ ] **Semana 5-6**: PR reviewed y merged
- [ ] **Semana 6**: Feature deployed a producción
